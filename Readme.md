# Chai & Co. Cafe Website

A fully responsive 8-page cafe website built with **HTML5** and **CSS3** for the Web Engineering course assignment.

## Live Demo
https://chai-and-co-cafe-website.vercel.app/

## Pages
| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero section, why choose us, popular items |
| About | `about.html` | Cafe story and team |
| Menu | `menu.html` | Hot drinks, snacks, desserts and cold drinks tables |
| Gallery | `gallery.html` | Photo gallery grid |
| Specials | `specials.html` | Offers and combo deals |
| Reservation | `reservation.html` | Table booking form |
| Reviews | `reviews.html` | Customer reviews |
| Contact | `contact.html` | Address, hours and contact form |

## Features
- Fully responsive (mobile, tablet and desktop)
- CSS-only hamburger menu on small screens
- CSS Grid and Flexbox layouts
- Sticky navigation bar with active page highlight
- Styled tables and forms
- Single shared stylesheet (`style.css`)
- No JavaScript or external libraries

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, Media Queries, CSS Variables)

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/AsimSiddiqui793264/chai-and-co-cafe-website.git
   ```
2. Open the folder and double-click `index.html` in any browser.

## Responsive Design
The layout adapts using media queries. Below 800px the grid becomes a single column and the navigation collapses into a hamburger menu.
